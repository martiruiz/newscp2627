Understand how ANY / ALL work

ANY

Shows posts that match at least one of the selected values.

→ In “Club”, select Real Madrid + FC Barcelona
→ You’ll see posts about Real Madrid OR Barcelona

ALL

Shows posts that match all selected values at the same time.
Useful for finding collaborations or combined appearances.

→ In “Entity”, select Brand + Player
→ You’ll only see posts where a brand AND a player appear together
